# Ember III round 7 — physics twins: conservation stable under continuous learning

**Date:** 2026-07-19
**Location:** `research/ember3_scale160m/` (scripts `run_twins.py`, `prep_data_gpt2.py`)

## What was added

- Round-7 twins experiment: `ember_v1_mixed` (SECAttention + XiNorm + RBFResidual +
  global PAC conservation) vs `vanilla_mixed` (matched no-physics control from
  cradle's telemetry campaign) under identical continuous learning on WT103
  (GPT-2 tokenization, SEQ 256, native objectives, pure-CE measurement).
  Cradle's `ember/` package + both checkpoints staged to CT103 `/data/ember3/twins`.

## Findings (single seed per cell; full detail in journals/2026-07-19_round7_twins.md)

1. **First-ever datapoint on PAC conservation under open-ended continuous
   updating: STABLE, and tightening** — conservation loss falls 30–40% over 10k
   updates on new-domain text in every ember arm. The constraint coexists with
   adaptation.
2. **Gate results are architecture-robust**: same qualitative gate ordering in both
   twins as in pythia (rounds 5–6) — the rung-1 conclusions generalize.
3. **Headroom confound acknowledged**: ember starts ~0.43 nats better (pretraining
   lineage) and stays better absolutely; vanilla gains more from adaptation —
   NOT physics-attributable. Matched-headroom design queued.
4. One twin-attributable gap: on the identical fresh segment, vanilla's
   within-segment CE trend is 2.2x worse than ember's, stable all run —
   instrument-caveated, mechanism unresolved.
