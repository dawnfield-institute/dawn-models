# Ember III round 5 — rung 1 at 160M on the 3090: toy gate ordering does not replicate

**Date:** 2026-07-19
**Location:** `research/ember3_scale160m/` (new experiment, standard structure —
sibling to `research/tinycimm/TinyCIMM-Euler/experiments/ember3_drift/`)

## What was added

- New experiment `ember3_scale160m`: gate-origin arms on pythia-160m under continuous
  full-rank next-token learning on WikiText-103 (10k x 512-token chunks, doc-order
  stream), run on node1's RTX 3090 inside CT103. Pre-registered design in README +
  runner docstring. Scripts: `prep_data.py`, `run_scale160m.py`, `analyze_scale.py`,
  `remote.ps1`.
- Infra: `/data/ember3` on CT103 (venv w/ torch 2.6.0+cu124, HF cache, tokenized
  WT103, results; ~4.5GB, root disk untouched, removable in one rm -rf).

## Findings

1. **The toy ordering (err > rand > ent) did NOT replicate.** Both informed gates
   lose to the rate-matched random gate on stream edge and held-out generality
   (non-overlapping incl. a CUDA-jitter repeat); err ≈ ent on competence.
2. **Origin separates drift, not competence**: the endogenous gate churns the
   representation (drift AUC 0.178 vs 0.03–0.05 all other arms) with no performance
   divergence — the toy's ossification signature inverted into a churn signature.
3. **Random 50% thinning matches ungated held-out generality with half the updates.**
4. Mechanistic hypothesis: WikiText's high-loss tail is aleatoric-heavy, so
   difficulty-threshold gates spend updates on the least transferable text; toy
   surprise was epistemic. **Refined thesis: exogenous signal + a selection rule
   that separates reducible from irreducible surprise (gate on learnability).**
5. Pre-flight catch: transformers loads the fp16 checkpoint dtype → pure-fp16
   training NaN'd instantly and the NaN silently closed the err gate forever
   (NaN >= median is False). Fixed: explicit fp32 + hard crash on non-finite loss.

Sanity anchors passed (frozen ppl ~34–37 = published ballpark; all adaptive arms
improve held-out 3.59 → 3.26–3.31). 68 GPU-minutes total.
